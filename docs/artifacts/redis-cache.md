## Краткое описание

Описание паттерна Cache-Aside для ускорения API.

## Полное описание

### Цель
Ускорить время ответа API с 500мс до 50мс.

### Решение
Использовать паттерн Cache-Aside с TTL 300 секунд.

#### Алгоритм:
1. При запросе проверяем Redis
2. Если ключ есть — возвращаем из кэша
3. Если нет — идём в PostgreSQL, сохраняем в Redis

### Критерии приёмки
- Время ответа < 100мс при RPS > 100
- Hit rate кэша > 80%
