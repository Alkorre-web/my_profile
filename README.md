# Portfolio Website — Системный аналитик

Веб-приложение для демонстрации навыков системного аналитика.

## 🚀 Стек технологий

- **Backend:** Python, FastAPI
- **Database:** PostgreSQL, MongoDB, Redis
- **Frontend:** HTML5, CSS3, JavaScript
- **DevOps:** Docker, Nginx

## 📦 Установка и запуск

### Требования
- Python 3.13+
- Docker и Docker Compose

### Запуск через Docker

```bash
docker-compose up -d
